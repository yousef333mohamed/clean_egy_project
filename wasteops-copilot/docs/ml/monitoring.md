# ML monitoring

Monitor request count/latency/failures, bounded model-version usage, freshness, missing-feature rate, baseline fallback, unavailable models, prediction distributions, data quality, drift, and confirmed-outcome performance. Traces contain model, version, entity count, horizon, duration, and warning count—not complete feature vectors.

Performance is calculated only after confirmed labels arrive. Historical analytics and RAG remain available during ML outages. Predictive decisions become insufficient-context responses and never receive mock substitutions.
